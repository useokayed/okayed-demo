# Okayed demo

Two small sample apps (iOS and Android) checked by [Okayed](https://github.com/useokayed/action) on every pull request.

Open the pull requests tab to see what Okayed posts: a Ship Score, every rejection risk with the file, line, and the official Apple or Google rule, and inline notes on the changed code.

Run it yourself:

```bash
npx okayed ios-app
npx okayed android-app
```
